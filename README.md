# SanctuSonuS Jump

**Spr3ad Th3 Lov3**

A tap-to-jump arcade game made with Unity, playable in the browser.

Tap to jump, dodge the obstacles, and see how high you can climb. Pick your character, enter your IGN, and beat your best score.

Every run is checked by the server and goes on the online leaderboard: the top 10 overall, the top 10 for each character, and the top 100 in a scrollable list, with your own rank shown underneath.

This repository holds the WebGL build served by GitHub Pages.
