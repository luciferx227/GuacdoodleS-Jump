# SanctuSonuS Jump

**Spr3ad Th3 Lov3**

A tap-to-jump arcade game made with Unity, playable in the browser.

Tap to jump, dodge the bars, and see how high you can climb. Pick your character colour, enter your IGN, and beat your best score. Your scores are saved in your browser.

This repository holds the WebGL build served by GitHub Pages.
